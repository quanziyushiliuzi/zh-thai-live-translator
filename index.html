两个人各开这个页面就行，不用房间、不用码：你说中文，她那边听到泰语；她说泰语，你这边听到中文。

打开页面就自动同步

不用建房间、不用输码：所有打开这个页面的人都在同一个公开对话里。你说话或打字，翻译完会自动发给所有打开页面的人，对方那边会读出来。不想同步时，把页面关掉就行。

这是公开对话：所有正打开这个页面的人都能收到你说的话，也会听到别人说的。别在这里说密码、验证码这类隐私内容。

点一下开始听，再点一下停

点自己语言的按钮开始听：说完一句自动翻译并读出来，读完会接着听下一句，不用每句都点。再点一下按钮结束。说短句、慢一点，翻译更准。

语音诊断（点麦克风后看这里：识别的每一步和返回的错误码都会写在这里，不会再静默失败）

  • 先查代理分流（你已经开代理时最常见）：安卓 Chrome 的网页语音识别是把声音交给手机系统的语音服务去识别的，它的流量不跟网页走同一条路。代理开「规则 / 分流」模式时，这部分流量可能被直连绕过，在国内连不上就一直没结果——把代理切到「全局模式」，再点一次麦克风试试；同时确认手机的「默认语音输入 / 语音服务」是可用的。切全局后还不行，就用办法二。
  • 办法一：在 Chrome 里、代理切「全局模式」后重新点麦克风试一次；还不行就换 Edge 打开这个页面再点麦克风。不要用安卓自带浏览器打开——它们大多没有网页语音识别。
  • 办法二（不用换浏览器）：用下面的打字框，点一下输入框，再点手机键盘上的麦克风图标说话——那是手机系统自己的语音输入，不经过浏览器，文字进框后点「发送」照样翻译并读出来。
  • 办法三：直接打字发送，翻译和朗读都不受影响。

用之前知道这几点

  • 全程要联网：语音识别、翻译、同步都走网络。
  • 第一次点麦克风，浏览器会问麦克风权限，点「允许」。
  • 安卓自带浏览器（vivo / iQOO、华为、小米自带浏览器等）大多不支持网页语音识别，点了麦克风也不会出文字，页面会弹出红色提示牌说明原因和办法；要语音说话请用 Chrome / Edge 打开本页，或用打字框 + 键盘上的麦克风图标说话。iPhone Safari 同样不稳，处理办法相同。
  • 对话是公开同步的：所有打开这个页面的人都能看到、听到，不要说隐私内容；不存录音，翻译文字走免费翻译接口。
